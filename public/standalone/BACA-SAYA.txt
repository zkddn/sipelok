==============================================================
  SIPELOK — Presensi Piket Loket Pelayanan BPS Kab. Konawe
  Versi TANPA NPM  (HTML + CSS + JS murni + PHP + MySQL)
==============================================================

TIDAK PERLU: Node.js, npm, build, atau instalasi paket apa pun.
HANYA PERLU: XAMPP (Apache + PHP + MySQL).

INSTALASI (±10 menit):
  1. Instal XAMPP, jalankan Apache + MySQL.
  2. Salin SELURUH folder "sipelok" ini ke:
        C:\xampp\htdocs\sipelok
  3. Buka http://localhost/phpmyadmin -> menu Import ->
     pilih file  database/sipelok.sql  -> Go.
  4. (Opsional) sesuaikan  api/config.php  dan ganti API_KEY.
  5. Buka  http://localhost/sipelok/
     -> badge kanan-atas berubah "MySQL Aktif" = berhasil.

AKUN ADMIN BAWAAN:  admin / bpskonawe   (segera ganti sandi!)

AKSES HP PETUGAS (satu Wi-Fi kantor):
  - Cek IP PC: CMD -> ipconfig -> IPv4 (mis. 192.168.1.10)
  - Buka http://192.168.1.10/sipelok/loket.html di PC loket
  - Petugas cukup SCAN QR yang tampil (tidak perlu mengetik).

HALAMAN:
  index.html    beranda / hub
  loket.html    layar PC front office (QR + feed langsung)
  scan.html     presensi di HP (buka via QR)
  admin.html    rekap, jadwal piket, petugas, akun
  panduan.html  panduan instalasi lengkap (buka di browser)

CATATAN:
  - Gambar QR memakai layanan qrserver (butuh internet di PC
    penampil). Tanpa internet, tautan scan tetap bisa diketik.
  - Foto atribut tersimpan sebagai file di  api/uploads/
  - Tanpa server (dibuka langsung dari file) aplikasi otomatis
    menjadi MODE DEMO (data di localStorage) — tetap bisa dicoba.
  - Panduan interaktif: buka panduan.html di browser.

DUKUNGAN: lihat panduan.html (tab Uji Koneksi & Checklist).

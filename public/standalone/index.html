Instalasi Cepat — Tanpa npm

Siap jalan dalam 4 langkah

1Pasang XAMPP
Jalankan Apache + MySQL dari XAMPP Control Panel.
2Salin folder
Taruh folder sipelok ke C:\xampp\htdocs\.
3Impor database
Buka phpMyAdmin → Import → pilih database/sipelok.sql.
4Buka aplikasi
Akses http://localhost/sipelok/ — badge berubah MySQL Aktif.

Rincian lengkap (akses lewat IP kantor untuk HP petugas, endpoint API, keamanan) ada di Panduan Instalasi.
